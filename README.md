# Сохранения Factorio → Google Диск

Простая программа на Python 3.10+ для Windows, Linux и macOS. Ждёт завершения процесса игры
и затем копирует новые/изменённые ZIP-файлы из папки saves на Google Диск.
Программу нужно оставить открытой во время игры и до завершения загрузки бэкапа. Сначала сохраните мир в игре
или включите автосохранение: программа копирует уже созданные файлы, а не память игры.

## Настройка один раз

1. Установите Python 3.10 или новее: https://www.python.org/downloads/
   В Windows отметьте «Add python.exe to PATH».
2. Установите rclone: https://rclone.org/downloads/
   Добавьте папку с rclone в PATH (или положите rclone.exe рядом с программой в Windows).
   Проверьте командой `rclone version` в новом терминале.
3. Выполните `rclone config`:
   - `n` — новый remote; имя: `gdrive`;
   - тип хранилища: `drive` (Google Drive; выбирайте по названию, номера меняются);
   - client_id и client_secret оставьте пустыми;
   - доступ: `drive.file` — только файлы и папки, созданные rclone;
   - дополнительные настройки оставьте по умолчанию;
   - для входа через браузер выберите Yes; войдите в нужный аккаунт;
   - Shared Drive: No, если используете личный Google Диск;
   - сохраните настройку и выйдите (`q`).
   Пароль Google программа не получает. Авторизацию хранит rclone на вашем компьютере.
4. Распакуйте файлы программы в отдельную папку.

## Запуск

Windows: дважды нажмите `start_windows.bat`.
Или выполните в терминале из папки программы:

```sh
python factorio_backup.py
```

Linux/macOS: используйте `python3` вместо `python`.
В Google Диске автоматически появится папка **Factorio Backups**.

Папка определяется автоматически:
- Windows: `%APPDATA%\Factorio\saves`
- Linux: `~/.factorio/saves`
- macOS: `~/Library/Application Support/factorio/saves`

Для portable-версии, серверной установки или нестандартного пути:

```sh
python factorio_backup.py --saves "D:\Games\Factorio\saves"
```

Проверять завершение процесса раз в 5 секунд (это не периодический бэкап):

```sh
python factorio_backup.py --interval 5
```

Дождаться запуска и закрытия игры, выполнить одну загрузку и выйти:

```sh
python factorio_backup.py --once
```

После завершения работы планировщика ненулевой код означает ошибку.
Пустая папка saves допустима: файлы появятся после первого сохранения.
Остановка — Ctrl+C. Для постоянной работы после входа в Windows можно поместить
ярлык на start_windows.bat в папку автозагрузки Win+R → `shell:startup`.
Не запускайте несколько копий с одинаковой целевой папкой одновременно.

## Условие запуска бэкапа

В Windows отслеживается процесс **factorio.exe**, в том числе для Factorio:
Space Age 2.0.72. Надпись «Factorio: Space Age 2.0.72» на скриншоте — заголовок
окна, а условие завершения привязано к исполняемому файлу. Его имя можно проверить
в Диспетчере задач → Подробности. Для переименованного exe укажите
`--process-name "другое-имя.exe"`.

- При запуске программы с уже открытой игрой она ждёт её закрытия.
- Если игра закрыта, программа ждёт запуска, затем закрытия; сразу бэкап не делает.
- Если открыто несколько процессов с этим именем, загрузка начинается после закрытия всех.
- После успешного бэкапа программа ждёт следующую игровую сессию.
- Состояние процесса проверяется каждые 2 секунды. Это задержка обнаружения закрытия,
  а не таймер создания бэкапов. Очень короткий запуск между проверками может быть пропущен.
- Если отправка не удалась, программа повторяет попытку, пока игра закрыта.
- При аварийном завершении игры копируются последние существующие сохранения.
  Программа сама не заставляет игру сохранять мир при выходе: сохранитесь перед закрытием.
- `--once` также ждёт завершения игры, затем выходит после одной попытки загрузки.

## Как работает копирование

- Обрабатываются все `.zip` непосредственно в папке saves, включая автосохранения.
- Программа ждёт завершения записи, делает временную копию и проверяет ZIP/CRC.
- Изменения определяются по SHA-256; rclone проверяет необходимость передачи
  при перезапуске программы. Временная копия требует свободного места размером
  с одно сохранение. Первое сканирование большой папки может занять время.
- Файл с тем же именем обновляется на Диске. Отдельный архив версий не создаётся;
  автосохранения `_autosave1.zip` и т. п. тоже обновляются.
- Удаление локального файла не удаляет копию с Диска. Локальные сохранения программа
  не изменяет. Сбой загрузки повторяется на следующем проходе.
- Для двух компьютеров используйте разные целевые папки через
  `--remote "gdrive:Factorio Backups/PC1"`, чтобы избежать перезаписи одноимённых миров.
- После отключения интернета программа продолжит попытки. Если авторизация истекла,
  выполните `rclone config reconnect gdrive:`.
- Не передавайте конфигурацию rclone другим людям: в ней находится токен доступа.

## Восстановление

Скачайте нужный ZIP из папки Factorio Backups в Google Диске, закройте Factorio
и скопируйте ZIP в папку saves. Затем откройте игру и выберите «Загрузить игру».
Если файл уже существует, сначала сохраните его отдельную копию.

## Проверка перед постоянным использованием

Запустите `python factorio_backup.py --once`, запустите Factorio, сохраните мир и закройте игру. Убедитесь, что ZIP появился на Диске,
скачайте его и проверьте загрузку в Factorio. Реальная отправка требует вашей
локальной авторизации; разработческие тесты не подключаются к Google.
